# Security

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/axvilab/wsbro/security/advisories/new)
or by email to axvi.dev@gmail.com. Do not open a public issue.

You will get an answer within a few days. Once a fix is released, the advisory is published with credit
to the reporter, unless you prefer otherwise.

## Supported versions

Security fixes go into the latest release.
