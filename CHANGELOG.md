# Changelog

## 0.1.0 (2026-04-04)

Initial release.

### Features
- Pusher protocol compatible WebSocket server
- Public, Private & Presence channels
- Client events (whisper)
- HMAC request authentication
- Rate limiting (configurable per connection)
- Webhooks (connection, channel, member events)
- Horizontal scaling via Redis and NATS adapters
- Built-in real-time dashboard with password protection
- Metrics endpoint
- Graceful shutdown
- Configuration via environment variables
- Docker support
